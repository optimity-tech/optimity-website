
## Design System
Always read DESIGN.md before making any visual or UI decision.
All fonts, colors, spacing, and aesthetic direction are defined there.
Do not deviate without explicit user approval.
Enforce the "Content Integrity" section: never render invented client names,
logos, or numbers; label sample/illustrative artifacts; anonymized-by-default proof.
In QA mode, flag any code that doesn't match DESIGN.md.
